# Code of Conduct

This project is committed to a respectful, evidence-focused environment.
Contributors must communicate professionally, welcome good-faith questions,
credit others' work accurately, protect private information, and avoid
harassment, intimidation, discrimination, or deceptive claims.

Project maintainers may edit, reject, or remove contributions and interactions
that violate these expectations. For a sensitive concern, contact the
[repository maintainer](https://github.com/limingrui679-design) privately when a
private channel is available. If none is available, open a minimal issue asking
for private follow-up without including sensitive details.
