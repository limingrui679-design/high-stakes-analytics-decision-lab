Feedback design

Practice

Keep only the first occurrence of each number, in its original order. The input is [2, 1, 2].

A loop visits the first 2. Because it appears twice, the loop removes the first 2 from the list it is traversing. What order will the remaining values have?

Start with an empty output. Look at each value once in its original order. Append it only if it has not appeared before.

input        2      1       2
output      [2]   [2, 1]  [2, 1]

The first occurrence determines the position.

Both designs have 60 seconds of practice. The transfer task also measures time to first response.

Independent transfer

A visitor taps gates in the order C, A, B, C, B, D. Keep each gate only on the first visit. Enter the gate order and explain how you decided which visits to keep.

Study protocol and scoring guide

For research, assign one variant per learner within baseline-skill blocks. Give both groups the same input, 60 seconds to study and the same unaided transfer item. Primary outcome is exact first-attempt transfer order. Record independent completion time separately. Score explanations blind on two criteria, one point each for retaining the first occurrence and preserving relative order. Record immediate practice and delayed transfer separately. This demonstration stores no research records.
